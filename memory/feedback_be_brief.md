2026-11-10, Tiran, three times in one session: "These AI summaries are way too long", "shorten the README
file - its too verbose" (`caruca/save_pash_py/README.md`, cut from ~230 to ~90 lines), and then as a standing
rule: "you need to be concise, and carefully decide when to describe details and when to stay at 20k feet
level. you are being too verbose".

**Why:** he reads to find things (code, files, links, the answer), not narration; long text hides it.

**How to apply:**
- Answer the question first, in a few lines, with links. No recap of everything done in the turn.
- Default to the 20,000-ft view. Give detail only when it changes what he does next (a decision, a
  surprise, an error, a number he asked for) — and then only that detail.
- Status updates: one or two lines. Final replies: short; lists only when they save words.
- Docs/READMEs: what it is, links, rules as a table, how to rerun. Keep tables he relies on (e.g. the
  "See the output" links table).
- Plain language still applies ([[feedback-plain-language]]): short is not shorthand.
