Tiran dictates many messages, so project names arrive as speech-to-text guesses. Seen in his messages: "Karuka"
for **Caruca** (he corrected it himself on 2026-11-26: "Karuka is spelled with a C. Caruca"), "Quokka" for
**Koala**, "Naivella LLM" for **naive LLM**, "Herder" for **Herdr**, "patch compiler" for **PaSh compiler**,
"ista" for **ISSTA**, "ASC" for **USENIX ATC**, "Northern Theological Engineers" for Morton Thiokol engineers
(Tufte's Challenger example).

**How to apply:** read through the misspelling to the project name, and always write the correct spelling in
documents, code and replies; never copy the dictated form into a report.
