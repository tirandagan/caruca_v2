**How each benchmark script was run.** Each script ran once under plain bash, which gives the reference output and time, and once under PaSh with each of four sets of annotation files; every set is a copy of PaSh's own package with one source's files swapped in for the commands that source has, and PaSh's own files kept for the rest. For every run we recorded whether the output matched bash's byte for byte, which commands PaSh split into pieces, and the seconds taken.
